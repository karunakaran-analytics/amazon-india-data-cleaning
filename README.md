# Amazon India Data Cleaning Project

## 📊 Project Overview
This project focuses on cleaning and transforming a raw Amazon India dataset into a structured format suitable for analysis and reporting. The goal is to practice real-world data cleaning and transformation using Power BI.

---

## 🛠 Tools Used
- Power BI (Power Query) → Data Cleaning and Transformation
- Excel → Data Viewing and Validation  

---

## 📂 Dataset Information
A sample Amazon India dataset in CSV format was used for learning purposes. The dataset was cleaned and transformed to remove inconsistencies and prepare it for analysis.

---

## 🔄 Data Cleaning & Transformation Steps (Power Query)

The following transformations were applied:

- Changed Data Types for all relevant columns  
- Removed Top Rows and Bottom Rows  
- Promoted Headers  
- Removed Unnecessary Columns  
- Removed Duplicate Records  
- Applied Trim and Clean functions to remove extra spaces  
- Filtered Rows based on conditions  
- Converted text using Capitalize Each Word and Upper Case  
- Replaced Values to standardize data  
- Split Columns using Delimiter  
- Renamed Columns for better readability  
- Reordered Columns for logical structure  
- Added Custom Columns for derived calculations  
- Merged Columns where required  
- Duplicated Columns for transformation purposes  
- Extracted specific text values from columns  
- Created Conditional Columns for logic-based categorization  
- Added Index Column for row tracking  
- Sorted Rows for structured output  

---

## 🔁 Advanced Transformations (Query Duplication Technique)

To explore multiple transformation techniques, the main query was duplicated and different operations were performed:

- Pivot Columns for reshaping data into summary format  
- Unpivot Columns to convert structured data into analysis-friendly format  
- Group By operation for data aggregation and summarization
